# 4x4-Systolic-Array-for-Matrix-Multiplication
Designed and implemented a 4×4 Systolic Array in Verilog for high-throughput matrix multiplication, inspired by TPU architectures. Built modular Processing Elements (PEs) executing signed 8-bit multiply-accumulate (MAC) operations into 32-bit accumulators. Optimized row/column pipelining to maximize data reuse and added asynchronous resets.
